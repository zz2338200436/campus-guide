# 校园通——开发任务计划

## 一、项目开发目标

完成一个可运行、可体验、可答辩的"校园通"微信小程序，实现校园信息展示、校园导览、前端学习内容展示、收藏记录、个人中心等核心功能，满足《前端框架应用技术》课程期末大作业考核要求。

## 二、技术栈说明

| 技术 | 用途 |
|------|------|
| WXML | 页面结构设计 |
| WXSS | 页面样式设计 |
| JavaScript | 页面逻辑与数据处理 |
| JSON | 页面与项目配置 |
| 微信小程序组件 | view、text、image、swiper、map、scroll-view、button 等 |
| 自定义组件 Component | place-card、study-card、notice-item、favorite-btn |
| 微信小程序 API | wx.navigateTo、wx.setStorage、wx.getStorage、wx.showToast、wx.request |
| 本地缓存 | 保存登录状态、收藏记录、学习记录 |
| 设计模式 | 单例模式（用户状态管理）、观察者模式（收藏同步） |

## 七、开发顺序总结

```
项目初始化 + tabBar
  → 首页布局与数据加载
    → 校园导览 + 地图组件
      → 地点详情
        → 学习专区 + 学习详情
          → 自定义组件抽取（place-card / study-card / notice-item / favorite-btn）
            → 收藏功能（观察者模式）
              → 个人中心（单例模式）
                → 我的收藏 + 学习记录
                  → 公告通知
                    → wx.request 真实接口接入
                      → 异常兜底处理
                        → 真机测试 + Bug 修复
                          → 文档、PPT、视频
```
