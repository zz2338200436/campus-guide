# 校园通截图演示路径

本文档用于整理最终截图和演示顺序。建议用微信开发者工具或真机按同一设备尺寸截图，保证 PPT 和说明文档风格统一。

## 一、截图准备

建议先准备三个账号状态：

- 未登录：展示登录前的自然提示。
- 普通学生：使用 `20260001`，完成至少 1 个地点打卡、1 个收藏、1 个学习任务。
- 管理员：使用 `admin001`，展示运营中心。

建议截图前先完成这条数据准备路径：

1. 用 `20260001` 登录。
2. 进入导览页，打开图书馆详情并打卡。
3. 在图书馆详情收藏地点。
4. 回到首页，进入“新生生存路线生成器”，选择“入学报到”或“网络报修”。
5. 从生存路线步骤跳到关联地点详情。
6. 进入服务页，点击“校园卡与餐饮咨询”跳到学生食堂详情。
7. 进入学习页，打开第一条成长任务并标记完成。
8. 返回首页和我的页，确认探索、学习和收藏数据已经同步。
9. 切换 `admin001` 登录，进入运营中心。

## 三、推荐演示脚本

### 1. 新生第一次打开

从首页开始，说明产品不是简单信息展示，而是直接告诉新生“今天下一站去哪”。重点展示“新生生存路线生成器”入口、个人今日行动台和路线进度。

### 2. 生成一条生存路线

进入生存路线页，选择“入学报到”或“网络报修”，展示系统自动生成地点、服务、材料和行动顺序。强调这是项目主卖点。

### 3. 完成校园探索

进入导览页，打开图书馆详情，完成打卡。返回首页或我的页，展示路线进度和探索足迹刷新。

### 4. 解决真实校园问题

进入服务中心，展示高频服务和应急支持。点击某个服务跳转到关联地点详情，说明服务和地点不是孤立列表。

### 5. 推进学习成长

进入学习专区，展示三条成长路径。打开学习详情，点击“标记完成”，再回到我的页展示成长进度。

### 6. 管理员查看运营状态

使用 `admin001` 登录，进入运营中心，展示数据概览、内容健康检查和维护建议，说明项目具备产品运营思路。

## 四、截图质量检查

- 每张图只突出一个主题，避免同一页截图讲太多点。
- 首页、生存路线、导览、服务、学习、我的、运营中心至少各保留一张。
- 截图前确认页面没有 loading、空白区域或半截滚动条遮挡。
- 如果用开发者工具截图，建议固定同一机型尺寸。
- 如果用真机截图，建议关闭系统悬浮窗和通知栏干扰。
