# 校园通——测试报告

验证"校园通"微信小程序各功能模块是否按照需求分析与方案设计文档正确实现，确保：

1. 所有 P0 核心功能正常运行
2. 页面跳转、数据渲染、交互操作无异常

5. 异常场景有合理兜底处理

7. 不同机型适配正常

## 十、Bug 修复案例

### Bug 案例 1：地图标记点不显示

| 项目 | 内容 |
|------|------|
| **问题现象** | 进入校园导览页面后，地图组件正常加载，但建筑标记点（markers）不显示在地图上 |
| **原因分析** | 通过 AppData 面板检查 markers 数据，发现 latitude 和 longitude 字段为字符串类型（如 "23.0601"），而 map 组件要求经纬度必须为 Number 类型 |
| **解决方案** | 在 placeData.js 中将所有经纬度数据统一为 Number 类型；在 buildMarkers 函数中增加 `Number()` 转换保护 |
| **涉及文件** | `utils/placeData.js`、`pages/map/map.js` |
| **修复结果** | 标记点正常显示在地图对应位置 |

---

### Bug 案例 2：收藏后个人中心不刷新

| 项目 | 内容 |
|------|------|
| **问题现象** | 在地点详情页点击收藏后，切换到个人中心 tab，收藏数量未更新；需要退出再进入才能看到最新收藏 |
| **原因分析** | 个人中心是 tabBar 页面，使用 switchTab 切换时不会触发 onLoad，只触发 onShow。最初只在 onLoad 中读取收藏数据，onShow 中未重新读取 |
| **解决方案** | 引入观察者模式（FavoriteSubject），个人中心页在 onLoad 中注册观察者，收藏变化时主动 notify 更新；同时在 onShow 中也从缓存同步一次数据 |
| **涉及文件** | `pages/user/user.js`、`utils/favoriteSubject.js` |
| **修复结果** | 收藏操作后，个人中心实时显示最新收藏数量 |

---

### Bug 案例 3：未登录也能收藏

| 项目 | 内容 |
|------|------|
| **问题现象** | 未登录状态下，在地点详情页点击收藏按钮，收藏操作成功执行，数据写入了本地缓存 |
| **原因分析** | favorite-btn 组件的 onTap 方法中缺少登录状态判断，直接调用了 FavoriteSubject.add() |
| **解决方案** | 在 favorite-btn 组件的 onTap 方法开头增加 `UserManager.isLogin()` 判断，未登录时 Toast 提示"请先登录"并 return |
| **涉及文件** | `components/favorite-btn/favorite-btn.js` |
| **修复结果** | 未登录时点击收藏，提示"请先登录"，不执行收藏操作 |

---

### Bug 案例 4：学习记录重复

| 项目 | 内容 |
|------|------|
| **问题现象** | 多次进入同一个学习详情页，学习记录列表中出现多条相同内容的记录 |
| **原因分析** | addStudyHistory 函数直接 unshift 新记录，未对已存在的相同 id 记录进行去重处理 |
| **解决方案** | 在 unshift 之前先用 `filter(h => h.id !== item.id)` 移除已有的相同记录，确保同一内容只保留最新一条（移到列表最前面） |
| **涉及文件** | `utils/studyHistoryHelper.js` |
| **修复结果** | 重复浏览同一内容只保留最新一条记录，时间更新为最近浏览时间 |

---

### Bug 案例 5：空数据页面显示异常

| 项目 | 内容 |
|------|------|
| **问题现象** | 新用户首次进入"我的收藏"页面时，页面显示空白，没有任何提示信息，用户体验差 |
| **原因分析** | 页面 WXML 中只有 `wx:for` 列表渲染，未对空数组情况做条件判断，导致列表为空时页面完全空白 |
| **解决方案** | 增加 `wx:if="{{list.length === 0}}"` 条件判断，为空时展示 empty-state 组件，显示"暂无收藏，去逛逛吧"提示文字和跳转按钮 |
| **涉及文件** | `pages/favorite/favorite.wxml`、`components/empty-state/*` |
| **修复结果** | 空数据时展示友好的空状态提示，引导用户去浏览内容 |
