# 校园通企业演示录屏讲解稿

建议时长：3-5 分钟  
建议账号：`20260001`  
录制尺寸：微信开发者工具同一机型尺寸或真机竖屏

## 0. 开场介绍

画面：微信开发者工具打开首页。

讲解词：

大家好，这是校园通 Campus Guide，一个面向高校新生的校园服务微信小程序。它的目标不是简单展示信息，而是帮助学生快速回答三个问题：今天先去哪、事情去哪办、进度怎么看。

当前版本是企业演示版，重点展示微信小程序端体验，同时保留后续接入 Spring Boot 和 MySQL API 的扩展边界。

## 1. 首页：今天先去哪

操作：

1. 停留首页首屏。
2. 指向推荐下一站、路线进度和行动芯片。
3. 点击推荐下一站或常用入口中的导览。

讲解词：

首页是校园行动台。顶部直接给出“今天先去哪”，下面有推荐下一站、路线进度、服务入口和继续学习。学生打开小程序后，不需要在多个菜单里找功能，第一屏就能知道下一步可以做什么。

## 2. 校园导览：查地点和看路线

操作：

1. 进入导览页。
2. 在搜索框输入“图书馆”或“食堂”。
3. 切换一个分类。
4. 点击地点目录中的地点进入详情。

讲解词：

导览页面向学生做了降噪。普通用户看到的是查地点、看路线、搜索、分类和导航。内部坐标复核能力只在运营身份下出现，不会干扰学生完成核心任务。

这里可以搜索地点，也可以按教学、学习、生活、应急等分类快速筛选。点击地点后进入详情页。

## 3. 地点详情：收藏和打卡闭环

操作：

1. 在地点详情页查看地点信息。
2. 点击收藏。
3. 点击打卡。
4. 返回首页或“我的”。

讲解词：

地点详情不仅展示介绍，还能收藏和打卡。打卡后，首页路线进度和身份中心都会同步变化。这样地点、导览和个人进度形成了闭环。

## 4. 服务中心：事情去哪办

操作：

1. 进入服务中心。
2. 展示“去哪办 / 带什么 / 联系谁”承诺条。
3. 切换一个问题入口，例如网络报修或失物招领。
4. 点击服务卡片进入关联地点，或点击拨打电话。

讲解词：

服务中心把校园事务按问题组织。学生遇到报修、失物、证明、学籍事务或应急联系时，可以直接看到去哪办、带什么材料、联系谁。

服务不是孤立列表，它会关联到具体地点，也支持电话直达，适合真实校园服务场景。

## 5. 学习专区：成长和留存

操作：

1. 进入学习专区。
2. 打开任意学习详情。
3. 标记学习任务完成。
4. 返回“我的”。

讲解词：

学习专区用于沉淀课程和项目相关的成长路径。学生可以按任务学习，打开详情后标记完成。完成状态和学习记录会同步到身份中心，让这个小程序不只是一次性导览工具，也有持续使用价值。

## 6. 身份中心：进度怎么看

操作：

1. 进入“我的”。
2. 展示校园身份、收藏数、学习记录、最近探索和下一任务。
3. 可选：切换 `admin001` 展示内部运营入口。

讲解词：

身份中心汇总了用户状态，包括收藏、学习记录、探索进度、最近探索和下一项任务。学生可以在这里回看自己的校园行动轨迹。

如果切换到内部运营账号，还可以进入运营中心查看内容健康、数据概览和维护建议。这个能力作为内部视角补充，不会影响普通学生的主体验。

## 7. 结尾

画面：回到首页或 README。

讲解词：

总结一下，校园通当前企业演示版已经完成了从“校园信息展示”到“校园行动助手”的升级。它以微信小程序为主体验，覆盖地点导览、服务办理、学习成长和身份中心，同时通过统一 request 层和 adapter 预留后端 API 接入能力。

验证方面，项目提供 `npm test` 一键 smoke tests，用来保证工具层、服务层、用户隔离和关键产品文案稳定。
