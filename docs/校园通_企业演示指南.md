# 校园通企业演示指南

## 1. 演示定位

校园通当前版本是以微信小程序体验为核心的企业演示版。演示重点不是后台管理系统，也不是完整后端部署，而是展示一个校园服务产品如何帮助学生快速完成“找地点、办事情、看进度”的闭环。

一句话介绍：

`校园通是一款面向高校新生的校园行动助手，把地点导览、服务办理、公告通知和个人进度整合到一个微信小程序里。`

## 2. 推荐演示路径

### Step 1：首页行动台

打开首页，重点说明：

- 今日待办告诉用户下一步做什么
- 推荐下一站可以直接进入地点详情
- 路线进度显示校园探索状态
- 路线、服务、学习三个行动芯片覆盖高频任务
- 常用入口聚合服务、导览、学习和通知
- 最近访问支持继续学习或继续查看

### Step 2：校园导览

进入导览页，重点演示：

- 顶部提示把“查地点”和“看路线”说清楚
- 搜索“图书馆”或“食堂”
- 切换教学、学习、生活、应急等分类
- 查看地图点位和地点目录
- 从地点卡片进入地点详情
- 普通学生界面聚焦搜索、分类和导航；内部坐标复核只在运营身份下出现

### Step 3：地点详情

在地点详情页演示：

- 地点基础信息
- 收藏地点
- 探索打卡
- 查看关联服务
- 返回首页后路线进度同步变化

### Step 4：服务中心

进入服务中心，重点演示：

- “去哪办 / 带什么 / 联系谁”服务承诺条
- 按问题找入口
- 查看所需材料、办理地点、开放时间和联系电话
- 点击服务卡片跳转到关联地点
- 应急服务可直接拨打电话

### Step 5：学习专区

进入学习专区，重点演示：

- 学习路径和任务进度
- 打开学习详情
- 标记学习任务完成
- 学习记录同步到身份中心

### Step 6：身份中心

进入“我的”，重点演示：

- 当前校园身份
- 收藏数量
- 学习记录数量
- 最近探索和下一项学习任务
- 探索路线进度

## 4. 企业演示验收清单

- 首页第一屏能看出“今天先去哪”的产品价值。
- 导览页默认面向学生探索，不把坐标复查作为普通用户主功能。
- 服务中心能按真实问题找到办理入口。
- 收藏、打卡、学习完成后，身份中心能看到状态变化。
- README 首屏是产品介绍，不是提交包交付说明。
- `npm test` 可以一键运行 smoke tests。
- 代码仍可在没有真实后端的情况下完整演示。

## 5. 轻量 API 扩展说明

当前版本继续使用本地 Mock service，但请求结构会保留后端扩展边界：

```text
pages/*
  -> utils/request.js
  -> utils/requestAdapter.js
  -> utils/services/* 或未来 HTTP API
```

未来 Spring Boot API 可按以下资源拆分：

- `GET /api/home`
- `GET /api/places`
- `GET /api/places/{id}`
- `GET /api/notices`
- `GET /api/notices/{id}`
- `GET /api/services`
- `GET /api/studies`
- `POST /api/favorites`
- `POST /api/checkins`
- `POST /api/users/session`

本轮不实现完整 Spring Boot 后端，避免偏离“小程序演示观感优先”的目标。
