# 校园点位补全方案

本项目不依赖高德 API 补点，采用“OpenStreetMap 已有坐标 + 手绘地图候选点位 + 人工校准坐标”的方式维护广州应用科技学院肇庆校区点位。

## 当前状态

- 正式运行点位在 `utils/placeData.js`。
- 手绘地图候选点位在 `utils/campusSupplementPlaces.js`。
- 校验脚本在 `scripts/audit-campus-supplement-places.js`。
- 当前候选清单覆盖教学楼、宿舍楼、饭堂、入口、运动场、图书馆、行政中心、校医务室等核心区域。

## 使用流程

1. 运行校验脚本：

   ```bash
   node scripts/audit-campus-supplement-places.js
   ```

2. 查看输出中的三类结果：

   - `已存在`：候选点位已经能在 `placeData.js` 中匹配到正式点位。
   - `待补坐标`：手绘地图中有，但正式点位中还没有真实经纬度的点位。
   - `异常`：分类、名称或 mapX/mapY 不合法的数据。

3. 对 `待补坐标` 点位进行人工校准：

   - 参考学校手绘地图确认楼栋名称和大致位置。
   - 用腾讯地图、OSM、学校现场信息或手动选点方式获取 GCJ-02 坐标。
   - 补进 `utils/placeData.js`，并标注 `source: "手绘地图人工校准"`。

4. 再次运行校验脚本，确认该点位进入 `已存在`。

## 数据原则

- 不把未校准经纬度的候选点直接放进正式运行数据。
- 正式点位必须包含 `name`、`type`、`latitude`、`longitude`、`mapX`、`mapY`、`address`、`source`。
- 名称以学校手绘地图为准，必要时保留楼栋编号，例如 `S4笃行楼`、`J1至善楼`。
- 分类使用项目现有分类：`教学楼`、`学习场所`、`宿舍楼`、`生活场所`、`交通入口`、`办事服务`、`应急服务`、`运动场所`。
