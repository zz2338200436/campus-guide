# 企业小程序改版计划清单

## 目标

将当前“校园通 - 新生校园助手”升级为更专业的“智慧校园服务门户”企业小程序。整体方向从“课程展示型应用”转为“组织级校园服务平台”，突出可信、清晰、高效、可运营。

## 企业版定位

- 产品名称建议：智慧校园服务门户 / Campus Service Portal
- 核心用户：学生、教师、辅导员、后勤服务人员、内容管理员
- 核心能力：工作台、校园服务、地图导航、公告消息、个人中心、运营管理
- 视觉关键词：专业、克制、可信、政企感、数据化

## 阶段 1：企业级设计系统

- [ ] 统一全局视觉变量
  - 主色：`#0F172A`
  - 辅色：`#334155`
  - CTA：`#0369A1`
  - 背景：`#F8FAFC`
  - 正文：`#020617`
- [ ] 收敛渐变和装饰效果
  - 减少大面积渐变
  - 减少过重阴影
  - 页面背景改为浅灰白
- [ ] 统一卡片规范
  - 圆角控制在企业风格范围内
  - 卡片使用轻边框、弱阴影
  - 避免卡片套卡片
- [ ] 统一按钮规范
  - 主按钮用于关键操作
  - 次按钮用于辅助操作
  - 列表操作按钮尺寸稳定
- [ ] 统一字体层级
  - 页面标题、模块标题、列表标题、正文、辅助说明分别设定尺寸
  - 减少过大的营销式标题
- [ ] 统一图标风格
  - 使用线性、单色、功能型图标
  - 避免表情符号和装饰图形

## 阶段 2：首页改为企业工作台

- [ ] 首页标题从“新生导向”改为“校园服务工作台”
- [ ] 顶部增加身份和校区信息

  - 当前校区：广州应用科技学院肇庆校区
- [ ] 第一屏改为关键业务面板
  - 今日待办
  - 紧急通知
  - 常用服务
  - 最近访问
- [ ] 服务入口重组
  - 地图导览
  - 办事大厅
  - 报修服务
  - 公告通知
  - 学习资源
  - 我的收藏
- [ ] 首页数据摘要企业化

- [ ] 删除或弱化过于学生化的表达
