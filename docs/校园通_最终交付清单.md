## 四、推荐答辩演示顺序

1. 首页：展示常用入口、最新公告、继续学习和推荐学习。
2. 校园导览：搜索“图书”或“食堂”，切换分类，说明点位已和地点数据绑定。
3. 地点详情：演示登录前收藏拦截、登录后收藏成功。
4. 学习专区：搜索“API”或“观察者”，展示分类筛选和学习衔接区。
5. 学习详情：展示知识正文、代码示例复制、自动写入学习记录。
6. 个人中心：使用 `20260001` 登录，展示收藏数、学习记录数。
7. 我的收藏 / 学习记录：回看刚才操作结果，形成功能闭环。
8. 管理员识别：使用 `admin001` 登录，说明轻量管理员身份展示。

## 五、本地编译和验收步骤

1. 打开微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择：`D:\111\WeChatMiniProgram\campus-guide`。
4. AppID 使用测试号或课程作业可用配置。
5. 点击“编译”，观察控制台是否有红色错误。
6. 按首页、导览、地点详情、学习、学习详情、个人中心、我的收藏、学习记录、公告、服务的顺序验收。
7. 使用 `20260001` 登录后测试收藏和学习记录。
8. 使用 `admin001` 登录后验证管理员身份标识。
9. 终端执行以下 smoke tests，留作提交前自检记录：

```powershell
node tests/content-filter.test.js
node tests/request-services.test.js
node tests/utils-smoke.test.js
```
