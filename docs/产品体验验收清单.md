# 校园通产品体验验收清单

本文档用于从真实产品视角验收当前小程序。验收重点不是“页面是否存在”，而是用户是否能顺畅完成核心任务。

## 一、验收结论

当前版本定位为“新生校园助手 MVP”，已形成三条用户闭环和一条管理员闭环：

- 新生探索闭环：看下一站 → 进导览 → 地点详情 → 打卡 → 回到首页/我的查看进度。
- 校园服务闭环：进服务台 → 查看高频/应急服务 → 跳到关联地点 → 查看地点可办服务。
- 学习成长闭环：进学习页 → 选择成长路径 → 打开学习详情 → 标记完成 → 首页/我的同步进度。
- 管理运营闭环：admin001 登录 → 进入运营中心 → 查看数据概览、健康检查和维护建议。

## 二、用户路径验收

| 路径 | 验收动作 | 预期结果 | 状态 |
| --- | --- | --- | --- |
| 首页任务 | 打开首页，查看今日任务、下一站、首日路线 | 能明确知道下一站和路线进度 | 已完成 |
| 校园导览 | 进入导览页，查看首日路线和地图点位 | 能看到路线进度、地点列表和搜索筛选 | 已完成 |
| 地点详情 | 打开图书馆、食堂、行政办事大厅等详情 | 可收藏、可打卡、可查看相关服务和下一站 | 已完成 |
| 探索反馈 | 打卡后返回首页和我的页 | 首页下一站刷新，我的页出现探索足迹 | 已完成 |
| 服务中心 | 进入服务页，查看高频服务和应急服务 | 能看到材料、步骤、联系电话和关联地点入口 | 已完成 |
| 服务联动 | 点击服务卡片 | 跳转到对应地点详情 | 已完成 |
| 学习路径 | 进入学习页，查看三条成长路径 | 能看到每条路径进度和下一步任务 | 已完成 |
| 学习完成 | 打开学习详情并点击“标记完成” | 任务完成状态写入当前账号，首页/我的同步更新 | 已完成 |
| 个人中心 | 登录后进入我的页 | 能看到收藏、历史、探索、成长和管理员入口 | 已完成 |
| 运营中心 | 使用 admin001 登录并进入运营中心 | 能看到数据概览、健康检查、运营建议 | 已完成 |

## 三、异常与空状态验收

| 场景 | 预期表现 | 状态 |
| --- | --- | --- |
| 未登录收藏/打卡/完成任务 | 给出登录提示，不写入个人数据 | 已完成 |
| 普通用户访问运营中心 | 提示仅管理员可访问 | 已完成 |
| 服务筛选为空 | 显示自然空状态，提示切换分类或补充服务 | 已完成 |
| 学习任务全部完成 | 我的页显示成长路径已完成状态 | 已完成 |
| 运营健康无异常 | 展示内容结构健康说明和后续扩展建议 | 已完成 |

## 四、仍需真机验证

- 微信开发者工具编译和预览。
- 真机端地点导航能力。
- 真机端复制代码、复制坐标、Toast 和 Modal 表现。
- 不同屏幕尺寸下首页、服务页、学习页、运营中心滚动体验。
- 本地缓存被清空后，登录、打卡、收藏、学习完成状态是否能重新开始。

## 五、后续扩展建议

- 接入微信云开发，把本地数据迁移为云数据库集合。
- 对探索打卡加入定位校验，区分“点按钮记录”和“真实到达”。
- 运营中心增加真实编辑能力，支持新增、修改、下架地点/服务/公告/学习任务。
- 服务中心增加报修、失物招领、校历、常用电话等可提交表单。
- 学习成长系统增加提醒、目标天数和更完整的徽章体系。
