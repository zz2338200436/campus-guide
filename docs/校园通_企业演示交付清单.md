# 校园通企业演示交付清单

## 1. 交付定位

本清单用于企业演示版交付检查。当前重点是微信小程序体验、产品闭环、演示路径和轻量 API 扩展边界，不包含 Web 管理后台和完整 Spring Boot 后端。

相关材料：

- 演示指南：`docs/校园通_企业演示指南.md`
- 录屏讲解稿：`docs/校园通_企业演示录屏讲解稿.md`
- 截图清单：`docs/assets/screenshots/企业演示截图清单.md`

交付目标：

- 打开仓库能看出这是一个产品型微信小程序项目。
- 打开小程序能在首屏理解“今天先去哪”。
- 3-5 分钟内可以讲清地点导览、服务办理、学习成长和身份中心闭环。
- 本地演示数据可以稳定演示，后续可以平滑替换为 Spring Boot + MySQL API。

2. 打开导览页，搜索“图书馆”。
3. 进入图书馆详情，完成收藏和打卡。

## 5. 3-5 分钟讲解脚本

### 1. 首页：今天先去哪

说明首页不是功能堆叠，而是校园行动台。推荐下一站、路线进度、服务入口和继续学习共同回答“现在应该做什么”。

### 2. 导览：查地点和看路线

演示搜索“图书馆”或“食堂”，切换分类，点击地点进入详情。说明普通学生看到的是搜索、分类和导航，内部坐标复核不会干扰主体验。

### 3. 地点详情：状态闭环

演示收藏或打卡。返回首页或身份中心，展示状态同步。

### 4. 服务中心：解决问题

说明服务中心用“去哪办 / 带什么 / 联系谁”组织信息。点击报修、失物或咨询类服务，展示关联地点和电话能力。

### 5. 学习成长：长期留存

打开学习专区和学习详情，标记一个任务完成。说明学习记录和进度会沉淀到身份中心。

### 6. 身份中心：个人进度汇总

展示收藏、学习记录、探索进度、最近探索和下一任务。最后可用 `admin001` 补充内部运营视角。

## 6. 当前不交付内容

- 不交付 Web 管理后台。
- 不交付完整 Spring Boot 后端。
- 不交付生产微信登录。
- 不交付真实线上部署。

这些能力保留在后续路线中，不影响当前企业演示版展示。
