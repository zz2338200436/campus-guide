# 项目素材目录说明

本目录用于集中放置答辩和最终交付会用到的可视化素材。

## 目录约定

- `posters/`
  存放项目封面、项目总览海报、交付封面图。
- `screenshots/`
  存放微信开发者工具或真机截图，建议按 `S01-首页.png` 这样的编号命名。
