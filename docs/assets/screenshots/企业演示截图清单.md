# 企业演示截图清单

截图存放目录：`docs/assets/screenshots/`

命名规则：`Sxx-页面名.png`  
建议设备：同一微信开发者工具机型或同一真机竖屏  
建议账号：学生 `20260001`，内部运营 `admin001`

## 拍摄前准备

1. 执行 `npm test`，确认 smoke tests 通过。
2. 微信开发者工具重新编译项目。
3. 使用 `20260001` 登录。
4. 完成一次地点收藏、一次地点打卡、一次学习详情浏览和一次学习任务完成。
5. 截图前确认页面不在 loading 状态。

## 截图质量检查

- 画面无红色错误提示。
- 页面主体完整，不截半个卡片作为主图。
- 同一批截图使用同一机型尺寸。
- 不保留微信开发者工具无关调试面板。
- 文件名和本清单一致。
- 截图完成后把“状态”改为“已拍”。
