# 校园通——截图拍摄指引

适用目录：`D:\111\WeChatMiniProgram\campus-guide\docs\assets\screenshots`

本文档用于指导微信开发者工具或真机截图，确保答辩 PPT、测试报告和最终交付材料中的截图风格统一、信息完整。

## 拍摄前统一设置

1. 使用微信开发者工具重新编译一次项目，确认当前页面无红色报错。
2. 模拟器优先使用常见手机尺寸，避免过窄导致布局拥挤。
3. 截图前尽量隐藏无关调试面板，只保留页面主体。
4. 命名统一使用 `Sxx-页面名.png`。
5. 若同一页面需要“登录前 / 登录后”两种状态，可以在文件名后加短后缀，例如 `S09-个人中心-已登录.png`。

## 推荐拍摄顺序

1. 先拍未登录态页面。
2. 再使用 `20260001` 登录，拍收藏、学习记录、继续学习相关页面。
3. 最后使用 `admin001` 登录，补管理员标识截图。

## 截图清单

### S01-首页.png

- 前置条件：首次编译成功；若想让“继续学习”有内容，先登录并进入过任意学习详情页。
- 操作步骤：进入首页，停留在首屏。
- 画面重点：顶部主视觉、四个常用入口、继续学习、最新公告、推荐学习。
- 检查点：页面不要停在加载态；如果“继续学习”为空也可以拍，但建议额外补一张有学习记录的版本。

### S02-校园导览.png

- 前置条件：进入“校园导览”页。
- 操作步骤：在搜索框输入“图书”或“食堂”，再切换一次分类。
- 画面重点：静态校园导览图、点位标签、搜索框、分类胶囊、地点列表。
- 检查点：至少让“搜索 + 分类”两个特征同时出现在画面里。

### S03-地点详情.png

- 前置条件：已从导览页进入任意地点详情，推荐“图书馆”。
- 操作步骤：先拍未登录状态下的收藏按钮提示，再登录后拍可收藏状态。
- 画面重点：地点名称、类型、开放时间、介绍、收藏按钮。
- 检查点：建议最终保留“已登录可收藏”的版本，更适合答辩展示。

### S04-校园服务.png

- 前置条件：进入“校园服务”页。
- 操作步骤：停留在能看到服务分类和至少 2 到 3 条服务卡片的位置。
- 画面重点：服务分类、服务列表、统一卡片风格。
- 检查点：不要只截到顶部标题，尽量带出列表内容。

### S05-学习专区.png

- 前置条件：进入“学习专区”页。
- 操作步骤：输入关键词“API”或“观察者”，并保留学习衔接区。
- 画面重点：搜索框、分类筛选、学习衔接区、知识卡片列表。
- 检查点：如果已登录且有学习记录，优先拍到“继续学习”卡片。

### S06-学习详情.png

- 前置条件：从学习专区进入任意学习详情。
- 操作步骤：下滑到正文和代码示例同时可见的位置。
- 画面重点：标题、正文说明、代码块、复制按钮。
- 检查点：建议使用内容较完整的一条，如“常用小程序 API”或“单例与观察者模式”。

### S07-公告列表.png

- 前置条件：进入“公告通知”页。
- 操作步骤：停留在顶部排序说明与前几条公告都可见的位置。
- 画面重点：排序说明卡片、置顶数量、置顶公告和普通公告的层级区别。
- 检查点：要能看出“置顶优先，其次按日期倒序”的页面表达。

### S08-公告详情.png

- 前置条件：从公告列表进入任意公告详情。
- 操作步骤：停留在标题和正文首屏。
- 画面重点：标题、公告类型、发布时间、发布者、正文。
- 检查点：尽量选择一条置顶公告，展示会更完整。

### S09-个人中心.png

- 前置条件：建议拍两张。
- 操作步骤：
  1. 未登录时进入“我的”，拍未登录状态。
  2. 使用 `20260001` 登录后再拍一次。
- 画面重点：登录框、用户信息、收藏数、学习记录数。
- 检查点：若只保留一张，优先保留“已登录”版本。

### S10-我的收藏.png

- 前置条件：已登录，并至少收藏 1 个地点或学习内容。
- 操作步骤：进入“我的收藏”，切换 tab 到有数据的一类。
- 画面重点：tab 切换、收藏列表、卡片内容。
- 检查点：如果三类收藏都有内容，可以额外补一张多 tab 演示图。

### S11-学习记录.png

- 前置条件：已登录，并浏览过至少 1 条学习详情。
- 操作步骤：进入“学习记录”页。
- 画面重点：最近浏览列表、分类、时间信息。
- 检查点：建议让列表里至少有 2 条记录，这样画面更饱满。

### S12-异常态.png

- 前置条件：可选择以下任一异常态进行截图。
- 推荐场景：
  - 未登录进入学习记录页
  - 未登录点击收藏后的提示前后状态
  - 空收藏页
  - 搜索无结果后的空状态
- 画面重点：`empty-state` 组件、引导文案、无数据情况下的页面完成度。
- 检查点：建议优先拍“空收藏”或“搜索无结果”，展示会更直观。
