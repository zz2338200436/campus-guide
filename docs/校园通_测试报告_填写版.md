## 七、Bug 修复案例

### BUG001 地图标记点不显示

| 项目 | 内容 |
|---|---|
| 问题现象 | 地图页面可能出现 marker 无法显示或点击失效。 |
| 原因分析 | `latitude`、`longitude` 若不是 Number 类型，map 组件无法正确识别；marker id 与页面参数也需要保持一致。 |
| 解决方案 | 在 `pages/map/map.js` 中构建 markers 时使用 `Number()` 转换经纬度，并在 marker 点击时按 id 跳转详情。 |
| 涉及文件 | `pages/map/map.js`、`utils/placeData.js` |
| 修复结果 | marker 数据结构已符合 map 组件要求，待开发者工具验证展示效果。 |

### BUG006 开发者工具地图瓦片加载失败

| 项目 | 内容 |
|---|---|
| 问题现象 | 控制台出现 `Failed to load xmlhttprequest`、`rt*.map.gtimg.com/tile`、`加载瓦片发生错误`。 |
| 原因分析 | 原生 `map` 组件内部需要访问腾讯地图瓦片服务，开发者工具或当前网络环境可能关闭连接，导致渲染层报错；这不是项目 Mock 接口失败。 |
| 解决方案 | 导览页改为模拟校园平面导览图，不再实例化原生 `map` 组件，避免自动请求地图瓦片。 |
| 涉及文件 | `pages/map/map.wxml`、`pages/map/map.js`、`pages/map/map.wxss` |
| 修复结果 | 页面进入时不会请求地图瓦片，导览列表、筛选和详情跳转可稳定演示。 |

### BUG002 收藏后个人中心不刷新

| 项目 | 内容 |
|---|---|
| 问题现象 | 收藏变化后，个人中心收藏数量可能不能及时更新。 |
| 原因分析 | tabBar 页面切换不一定重新执行 `onLoad`，仅靠页面重新加载不稳定。 |
| 解决方案 | 使用 `favoriteSubject` 观察者模式，个人中心订阅收藏变化并在 `onShow` 再同步一次。 |
| 涉及文件 | `utils/favoriteSubject.js`、`pages/user/user.js` |
| 修复结果 | 收藏变化会触发订阅回调，个人中心数量可同步刷新，待本地验证。 |

### BUG003 未登录也能收藏

| 项目 | 内容 |
|---|---|
| 问题现象 | 未登录状态下点击收藏可能写入缓存。 |
| 原因分析 | 收藏按钮或请求层缺少登录态拦截时会直接执行写缓存。 |
| 解决方案 | `favorite-btn` 点击时先检查 `userManager.isLogin()`，`request.addFavorite` 也做二次拦截。 |
| 涉及文件 | `components/favorite-btn/favorite-btn.js`、`utils/request.js` |
| 修复结果 | 未登录只 Toast “请先登录”，不会写入收藏缓存。 |

### BUG004 学习记录重复

| 项目 | 内容 |
|---|---|
| 问题现象 | 多次进入同一个学习详情页可能出现多条相同学习记录。 |
| 原因分析 | 添加记录前如果不按学习 id 去重，会不断追加重复项。 |
| 解决方案 | `studyHistoryHelper.addHistory` 先过滤相同 id，再把最新记录放到第一条，并截取最近 20 条。 |
| 涉及文件 | `utils/studyHistoryHelper.js` |
| 修复结果 | 同一学习内容只保留最新一条浏览记录，最多保存 20 条。 |

### BUG007 按用户隔离后记录写入了但读不出来

| 项目 | 内容 |
|---|---|
| 问题现象 | 首页“继续学习”、学习记录页或收藏列表在登录后可能显示为空，但缓存里实际已经写入数据。 |
| 原因分析 | `storage.get(key, [])` 在读取对象分桶结构时会把对象判定为与数组默认值类型不一致，导致回退成空数组。 |
| 解决方案 | `favoriteSubject` 与 `studyHistoryHelper` 改为以 `null` 读取原始值，再自行兼容旧数组格式和新对象格式。 |
| 涉及文件 | `utils/favoriteSubject.js`、`utils/studyHistoryHelper.js` |
| 修复结果 | 不同账号的收藏和学习记录均可正常读写，首页和学习页的最近学习入口可正常取数。 |

### BUG005 空数据页面显示异常

| 项目 | 内容 |
|---|---|
| 问题现象 | 收藏、学习记录、公告、地点等列表为空时页面可能空白。 |
| 原因分析 | 列表只使用 `wx:for` 渲染，没有为空数组提供可见状态。 |
| 解决方案 | 抽取并复用 `empty-state` 组件，在各列表页加入空状态提示。 |
| 涉及文件 | `components/empty-state/*`、`pages/favorite/*`、`pages/studyHistory/*`、`pages/notice/*`、`pages/map/*` |
| 修复结果 | 空列表均有明确提示，待开发者工具验证视觉效果。 |
